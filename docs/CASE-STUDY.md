# Custom Shopify Fashion Store Development — NOVA E-commerce Theme

NOVA is a personal demonstration project, not a commissioned client store. The brief was to improve an existing Skeleton-based fashion theme while preserving merchant configuration and working native behavior.

## Work delivered

The existing hero, category cards, featured collection, navigation and footer were refined. A shared neutral design system and 4:5 cards connect the storefront. Collections now use native filters and pagination. Product options resolve real Shopify variants and synchronize server-rendered pricing, availability, selling plans and media. Cart mutations use real item keys and authoritative section responses, with read recovery when an outcome is uncertain. Search, recommendations and optional shared size guides demonstrate Shopify platform integration.

## Engineering evidence

Fifteen regression tests pass and Theme Check reports zero offenses on 66 files. The theme was uploaded as a separate unpublished preview; Horizon remains the live theme. Architecture, installation, merchant configuration and acceptance guides accompany the code.
