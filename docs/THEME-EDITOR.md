# Theme Editor configuration

Use the unpublished NOVA preview. Keep the currently published theme until acceptance is complete.

1. Set the existing font, background and brand color. Additional surface, muted, border and state colors are configurable; NOVA defaults follow the requested neutral palette. Review contrast after changing colors.
2. Header: choose the existing logo and main menu. Nested menu links render from Shopify navigation. Customer accounts follow the store configuration; search is independent.
3. Announcement: now belongs to the header group. Verify the shipping claim against actual shipping configuration; edit or hide it when unsupported.
4. Main hero: choose real desktop/mobile photography, content position and overlay. Keep image priority enabled only here. Confirm text contrast over the selected crop.
5. Categories: choose collections and optional custom images. Featured collection: choose a collection and product count. No arbitrary catalogue records are displayed.
6. Promotional hero: choose photography and confirm the Sale collection exists. The supplied CTA defaults point to new-arrivals and sale and remain editable.
7. Story: edit copy, optional image and CTA. Newsletter: edit heading/description; signup uses the native customer form and explicit consent.
8. Product template: gallery layout, quantity, optional vendor/share/dynamic checkout, shipping and returns text. Product details read the optional data model.
9. Collection template: enable image/filters/quick add and configure products per page. Configure actual available filters in Shopify Search & Discovery.
10. Footer: retain logo, description/menu and payment settings; populate real policy content in Shopify Admin.

Test live section add/remove/reorder and editor reload events. Local templates are starting configuration; preserve merchant edits before syncing theme files.
