# NOVA — Shopify Store

NOVA is a custom Shopify storefront developed as a portfolio project
to demonstrate professional Shopify theme development.

## Tech Stack

- Shopify
- Liquid
- HTML
- CSSx
- JavaScript
- Shopify CLI
- Git & GitHub

## Project Goals

- Build a complete Shopify storefront
- Develop reusable Shopify sections and blocks
- Implement product and collection experiences
- Implement cart and search functionality
- Use Shopify metafields and dynamic content
- Follow responsive, accessible and maintainable practices
